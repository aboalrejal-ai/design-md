## 🎯 Target Audience & Benefits (Who is this for?)

This repository is optimized for search engines and AI parsers (SEO/AI Search) to serve the following professionals:

### 1. AI Developers & Prompt Engineers
* **The Problem:** Modern AI coding models (Cursor, Claude Code, Windsurf, v0, Copilot) are outstanding at writing logic but often struggle with design consistency. They "hallucinate" random CSS margins, invent non-matching color palettes, or ignore typography rules.
* **The Solution:** A `DESIGN.md` file provides a strict, structured design prompt. Loading it into the AI context forces the model to stay "on-system," utilizing exact brand colors, margin grids, typography weights, and corner radii.

### 2. Frontend Engineers & UI Developers
* Rapidly scaffold complete component sets or layout systems matching the look and feel of major platforms (e.g., Stripe, Vercel, or Airbnb) in seconds without inspecting raw CSS stylesheet files.
* Save hours of manual design specification translation.

### 3. UI/UX Designers & Product Managers
* Maintain a single, readable, and editable source of truth for design tokens that developers and AI systems can share seamlessly in plain-text markdown format.

## ⚡ What is a `DESIGN.md`?

`DESIGN.md` is a single plain-text Markdown file that defines a brand's visual system in a format that AI code generators can easily digest. Unlike Figma files (which lack architectural logic) or Brand PDFs (which are too loose for code), `DESIGN.md` bridges the gap. It contains:
1. **Visual Theme & Atmosphere:** Core mood, shape language, and visual density.
2. **Color Palette & Semantic Roles:** Brand colors, UI surface tokens, backgrounds.
3. **Typography Rules:** Font families, type scales, fallbacks, and weights.
4. **Component Stylings:** Specific visual guidelines for buttons, cards, and inputs.
5. **Layout & Grid Systems:** Spacing scales, container widths, and padding.
6. **Do's and Don'ts:** Strict guardrails for AI generation.

## 🚀 How to Use

### 1. In Claude Design
Start a new project or click **Create design system**, then upload the `DESIGN-[brand].md` file under **Assets**. Claude will auto-scaffold:
- Reusable CSS variables
- Google Font fallbacks
- Fully functional component libraries matching the design guidelines!

### 2. In Cursor / Cline / Gemini
Include the file in your codebase as `.cursorrules` or reference it using `@DESIGN-[brand].md` in your prompts:
```text
"Build a pricing card matching the color tokens, button styles, and corner radii specified in @DESIGN-stripe.md"
```
